# scalping-trader

Agent Mistral (Agents SDK, `mistralai-agents`) : trader professionnel en scalping, réponses en
français, mémoire de toute la conversation, RAG sur les bibliothèques Vibe Work via `document_library`.
Aucun sandbox : aucune exécution de code.

Déploiement géré : `uv run --env-file .env agents deploy` depuis un clone du dépôt.
Discussion : Vibe Code Web (`https://chat.mistral.ai/managed-agents/scalping-trader`),
`agents chat scalping-trader`, ou `Agent.load_from(agent_name="scalping-trader")`.
